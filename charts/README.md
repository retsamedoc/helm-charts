# Helm charts overview

| Chart | Description |
| ----- | ----------- |
| [common](common/) | Function library for Helm charts |
| [deluge](deluge/) | Deluge is a lightweight BitTorrent client |
| [esphome](esphome/) | ESPHome is a system to control your ESP8266/ESP32 by simple yet powerful configuration files and control them remotely through Home Automation systems |
| [juicepassproxy](juicepassproxy/) | Proxy UDP requests to/from Juicebox EV chargers to MQTT discoverable by Home Assistant |
| [otbr](otbr/) | OpenThread Border Router (OTBR) connects a Thread network to the host infrastructure network |
| [retrom](retrom/) | A centralized game library/collection management service with a focus on emulation |
| [romm](romm/) | A beautiful, powerful, self-hosted rom manager and player. |
| [searxng](searxng/) | SearXNG is a privacy-respecting metasearch engine. Users are neither tracked nor profiled. |
| [spoolman](spoolman/) | Spoolman is a self-hosted inventory manager for 3D-printer filament spools |
