1. Get the application URL by running these commands:
  export POD_NAME=$(kubectl get pods --namespace {{ .Release.Namespace }} -l "app.kubernetes.io/instance={{ .Release.Name }}" -o jsonpath="{.items[0].metadata.name}")
  echo "Visit via: kubectl -n {{ .Release.Namespace }} port-forward $POD_NAME 8080:8080"
  echo "Open http://127.0.0.1:8080"

Or enable ingress.main / a Gateway API route and open that hostname.
